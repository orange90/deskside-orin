> 本文保留历史实施过程；已取消的扬声器和夜间告警功能以当前 README 为准。原始照片、录音、活动数据和运行日志不上传 GitHub。

## 01 · 核验主机并安装依赖

- 使用 Mac 上已有的 `ssh orin` 连接。主机为 `jetson-orin`，架构 aarch64，L4T R36.4.4，功耗模式 MODE_30W。系统报告约 61 GiB 可见 RAM。开始时系统盘可用约 47 GiB，盘为 eMMC。
- 摄像头节点 `/dev/video0`，用 `v4l2-ctl` 取帧成功，输出丢弃。PulseAudio 能枚举 Insta360 Mic Air RX 和本机模拟音频输出。
- 在 Orin 用一次交互式 sudo 运行安装脚本。CUDA 12.6.68、TensorRT 10.3.0、Docker、NVIDIA Container Toolkit、CMake、v4l-utils、tmux 已安装。Docker 已配置 NVIDIA runtime，并给现有部署用户授予 Docker 组访问。密码留在终端交互。
- 可复核的安装输出在 Orin 的 `logs/01-system-install.log`。截图见 安装过程中（原始证据本机留存） 和 安装版本核验（原始证据本机留存）。

## 02 · 下载模型和配置 Python

- Orin 直连 Hugging Face 域名连接被重置。RTMDet-tiny、RTMPose-s、Whisper base 和 Silero VAD 已传到 Orin。大文件用公开 CDN 的范围请求分块，完成后按模型 SHA-256 校验。
- 使用本地 Python 虚拟环境运行 FastAPI 和 OpenCV。ORT 在本机 arm64 初始化时出现进程断言，视觉部署改用 TensorRT。
- TensorRT 包需要 DLA 编译器和 CUDLA 动态库。用匹配本机 L4T 的 NVIDIA 包及 CUDA 12.6 的 CUDLA 包，在项目目录解包并通过启动脚本提供库搜索路径。
- RTMDet 公共导出图包含 5000 个候选的 TopK，超过 TensorRT 10.3 支持的 3840。已将 ONNX 图截到解码后的框和分类分数，将 person 类筛选和 NMS 移到 OpenCV，原始 ONNX 权重仍保留。TensorRT 引擎构建日志在 `logs/04-rtmdet-trt.log` 和 `logs/04-rtmpose-trt.log`。
